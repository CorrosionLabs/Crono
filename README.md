# CRONO

CRONO is an Android stopwatch designed to measure and record cycle times in industrial machinery, automated stations and repetitive processes.

## Features

- Measures time in seconds and hundredths of a minute.
- Start / Stop and Start / Reset timing modes.
- Configurable target cycle time.
- Cycle history, average time and graphical overview.
- CSV export for further analysis.
- Independent projects with their own settings and records.
- Project import and export.
- Optional sound feedback and support for Android volume buttons.
